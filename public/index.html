    Agent Deployment & Onboarding

    Deploy the lightweight endpoint monitoring agent to record process logs, file integrity, and USB connections.

    Deployment Guide

    Install and run SecureGuard Agent on target endpoints

    1. Prepare Python Environment

    SecureGuard agent is written in Python 3. Make sure python and pip are installed on the target machine.

    2. Install Required Modules

    Execute the following command in the target machine's command line to install telemetry and connection dependencies:

    $ pip install psutil websockets

    3. Run Endpoint Agent

    Launch the agent with the profile username of the employee to register it to the dashboard:

    $ python "Endpoint Monitoring Agent.py" --username Kumar
    Tip: You can use any employee profile name like 'rithish', 'vijay', or 'employee-07' to bind it.
